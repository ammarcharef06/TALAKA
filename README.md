# طَلَاقَة | TALAQA
### أكاديمية العرب السيادية للغة الإنجليزية — *From Zero to C2*

> توأم رقمي لمؤسسة تعليمية عريقة — أكاديمية إنجليزية كاملة End-to-End للعربي، من الصفر المطلق إلى C2.
> **بلا خادم. بلا حساب. بلا تكلفة. بلا تتبع.** كل شيء يعمل على جهازك وحده.

هذه النسخة (0.11.0) تشمل: **البوابة ← مكتب القبول ← تحديد المستوى التكيفي ← صحيفة النتيجة ← التسجيل ورقم الطالب وبطاقة الطالب ← الفصل الافتراضي (سبع محطات — 42 درساً حتى C2) ← ردهة التكرار المتباعد (SM-2 — 263 بطاقة) ← مقهى طَلَاقَة (أول حوار صوتي) ← قاعة الامتحانات المعتمدة (A1 حتى C2) ← السجل الأكاديمي الحيّ**.
بقية الأجنحة (المكتبة، قاعات الامتحانات، السجل والشهادة، Career Hub) في `docs/PLAN.md`.

---

## ما الذي يميزها؟
- **سيادة كاملة**: ملفات static خالصة تُستضاف أي مكان (GitHub Pages / Cloudflare Pages / IPFS / قرصك). لا خادم للتطبيق ولا مفتاح API ولا تحليل سلوكي.
- **Offline-first**: Service Worker يخزّن كل شيء؛ بعد أول زيارة تعمل حتى بلا إنترنت.
- **بياناتك ملكك**: السجل في IndexedDB على جهازك + تصدير «ملف بطاقتي JSON» — هوية تسافر معك.
- **اختبار يعمل كالمؤسسة الحقيقية**: محرك تكيفي لوجستي (تقريب Elo/IRT) عبر ثلاثة أقسام، وكل سؤال موسوم بخطأ عربي شائع — التشخيص نفسه هو العلاج.
- **محتوى تأسيسي حقيقي**: سبع محطات — «أول خطواتك»، «الجمل العاملة»، «الزمن يتكلم»، «لغة الحياة»، «الدقة والتحليل»، «الأسلوب والقوة»، و«الإتقان والبلاغة» — 42 درساً من الأصوات إلى القلب الشرطي ودقة المفردة C2، صوت المتحدث عبر Web Speech API، وقفل تتابعي يحترم ترتيب التعلم.
- **ردهة التكرار المتباعد**: 263 بطاقة مولّدة من دروسك — تُعاد لك قبل نسيانها بقليل بخوارزمية SM-2 الحقيقية (مع اختبارات آلية)، وتعمل بالكامل offline.
- **أول حوار صوتي حقيقي**: مقهى طَلَاقَة — سيناريو «أول طلب» مع الباريستا «بسام»، تعرّف كلام عبر Web Speech API مع بديل كتابة كامل، مطابقة ذكية للجمل (لا أوضاع «حضوري» جامدة)، سجل حوار، ودرجة تُحفظ في تقدّمك.
- **امتحانات معتمدة A1 حتى C2**: 12 و15 و16 و17 و16 و16 سؤالاً مسحوبة من بنك المعايرة، خيارات مخلوطة، مؤقّت، درجة نجاح 80%، ولا تصحيح قبل التسليم — والنجاح يُسجّل اعتماداً في سجلك.
- **سجل أكاديمي حيّ (Transcript)**: درجات الدروس، محاضر الامتحانات، الاعتمادات، وملخص ذاكرة المراجعة — وثيقة رسمية قابلة للطباعة تُحدَّث مع كل خطوة.
- **108 أسئلة معايرة** عبر S0→C2 — مولّدة ومُراجعة منطقياً بمتحقق آلي (`npm run validate`).

## التشغيل محلياً

```bash
npm install
npm run dev        # http://localhost:5173
```

## البناء والفحص

```bash
npm run validate   # متحقق بنك الأسئلة (بنية، تكرار، تطابق الإجابات)
npm run build      # فحص الأنواع + بناء حزمة static في dist/
npm test           # 51 اختباراً آلياً (تحديد المستوى، SRS، المنهج، النطق، الامتحانات المعتمدة)
npm run preview    # معاينة نسخة الإنتاج
```

## الحدود الصادقة (لا نكذب على طلابنا)
- النسخة الحالية تشمل **القبول، إثبات المستوى، 42 درساً (من S0 إلى C2)، ردهة مراجعة، مشهد مقهى واحداً، امتحانات A1 حتى C2، وسجلاً أكاديمياً حيّاً** — بقية الأجنحة (الشهادة الموقعة، المكتبة، Career Hub) تُفتتح مرحلة مرحلة، ولا نعرض واجهات تعلّم وهمية.
- **الاعتماد محلي** على هذا الجهاز ومسجّل في سجلك؛ الشهادة الموقعة رقمياً وشبكة التحقق الخارجية مرحلة لاحقة معلنة. لا نسمي المحضر «شهادة نهائية» قبل أن يصبح قابلاً للتحقق.
- **التعرف على الكلام** يعتمد على Web Speech API في متصفحك؛ بعض المتصفحات (خصوصاً Chrome) قد ترسل الصوت إلى خدمة المتصفح لتفريغه نصاً. البديل الكتابي يعمل دائماً وبلا إنترنت. أما النطق (speechSynthesis) فيعمل محلياً في الغالب.
- رقم الطالب **محلي** — لا معنى إثباتي خارجي حتى طبقة التوقيع الرقمي (مذكورة في الخطة).
- دقة تحديد المستوى ±مستوى تقريباً (كما أي Placement عالمي) — لذا نعرض «درجة الثقة» ويحق لك الإعادة.
- iOS يقيّد التخزين المحلي للـ PWA غير المثبتة — ثبّت التطبيق (أو حمّل ملف بطاقتك) لضمان بقاء هويتك.

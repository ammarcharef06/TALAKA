# طَلَاقَة | TALAQA
### أكاديمية العرب السيادية للغة الإنجليزية — *From Zero to C2*

> توأم رقمي لمؤسسة تعليمية عريقة — أكاديمية إنجليزية كاملة End-to-End للعربي، من الصفر المطلق إلى C2.
> **بلا خادم. بلا حساب. بلا تكلفة. بلا تتبع.** كل شيء يعمل على جهازك وحده.

هذه النسخة (0.1.0) تشمل: **البوابة ← مكتب القبول (وكيل سكريبتي) ← اختبار تحديد المستوى التكيفي ← صحيفة النتيجة الرسمية ← التسجيل ورقم الطالب وبطاقة الطالب ← مبنى الأكاديمية**.
بقية الأجنحة (الفصول، المكتبة، المقهى، SRS، الشهادات) في `docs/PLAN.md`.

---

## ما الذي يميزها؟
- **سيادة كاملة**: ملفات static خالصة تُستضاف أي مكان (GitHub Pages / Cloudflare Pages / IPFS / قرصك). لا خادم للتطبيق ولا مفتاح API ولا تحليل سلوكي.
- **Offline-first**: Service Worker يخزّن كل شيء؛ بعد أول زيارة تعمل حتى بلا إنترنت.
- **بياناتك ملكك**: السجل في IndexedDB على جهازك + تصدير «ملف بطاقتي JSON» — هوية تسافر معك.
- **اختبار يعمل كالمؤسسة الحقيقية**: محرك تكيفي لوجستي (تقريب Elo/IRT) عبر ثلاثة أقسام، وكل سؤال موسوم بخطأ عربي شائع — التشخيص نفسه هو العلاج.
- **108 أسئلة معايرة** عبر S0→C2 — مولّدة ومُراجعة منطقياً بمتحقق آلي (`npm run validate`).

## التشغيل محلياً

```bash
npm install
npm run dev        # http://localhost:5173
```

## البناء والفحص

```bash
npm run validate   # متحقق بنك الأسئلة (بنية، تكرار، تطابق الإجابات)
npm run build      # فحص الأنواع + بناء حزمة static في dist/
npm run preview    # معاينة نسخة الإنتاج
```

## البنية

```
src/
  screens/        البوابة، مكتب القبول، الاختبار، النتيجة، التسجيل، المبنى
  engine/         محرك تحديد المستوى التكيفي (placement.ts)
  data/items/     بنك الأسئلة (rules / vocab / reading) — JSON منفصل وقابل للتوسعة
  store/db.ts     IndexedDB + تصدير/استيراد بطاقة الطالب
  ui/             الختم (SVG هندسي خالص)، التأكيدات، باركود البطاقة
public/
  sw.js           Service Worker (سيادة: صفر اتصال خارجي)
  manifest.webmanifest   PWA — تُثبَّت كتطبيق
tools/              download-fonts.ps1 (خطوط ذاتية الاستضافة) · validate-items.mjs
docs/PLAN.md       الخطة الرسمية والمراجع والقرارات
```

## الحدود الصادقة (لا نكذب على طلابنا)
- النسخة الحالية تدير **القبول وإثبات المستوى فقط** — لا دروس بعد. لا نعرض واجهة تعلّم وهمية.
- رقم الطالب **محلي** — لا معنى إثباتي خارجي حتى طبقة التوقيع الرقمي (مذكورة في الخطة).
- دقة تحديد المستوى ±مستوى تقريباً (كما أي Placement عالمي) — لذا نعرض «درجة الثقة» ويحق لك الإعادة.
- iOS يقيّد التخزين المحلي للـ PWA غير المثبتة — ثبّت التطبيق (أو حمّل ملف بطاقتك) لضمان بقاء هويتك.

## 1. القاعدة الحاكمة

1. **لا محتوى منقول بلا حق**: كل نص تعليمي في TALAQA إما أصلي لصاحب المشروع،
   أو من مشروع يملكه صاحب المشروع نفسه، أو مذكور هنا صراحةً مع ترخيصه.
2. **لا تحميل خارجي**: لا CDN ولا خادم ولا API؛ كل المحتوى يُحزم مع التطبيق.
3. **المراجعة تُعلن ولا تُدّعى**: أي محتوى جديد يُوسم بأنه ينتظر المراجعة البشرية
   حتى تُتمّ فعلاً.
4. **الحدود الصادقة في README هي العقد**: أي إضافة جديدة تُحدِّث هذا الملف
   و`NOTICE` و`README.md` معاً.

## 6. إعادة توليد الاستخراج

```bash
node tools/import/learn-english.mjs --source "C:\path\to\Learn-English"
```

الأداة تقرأ ملفات المصدر مباشرة، وتُنتج JSON مطبّعاً + `manifest.json` +
`EXTRACTION_REPORT.md`. لا تكتب في `src/` إطلاقاً.

## 7. التحقق من البصمات

- `manifest.json` يحمل `sha256` لكل ملف مصدر، وبصمة مجمّعة للمصدر.
- `EXTRACTION_REPORT.md` يحمل بصمة المصدر نفسها.
- عند تحديث المصدر، تتغير البصمة؛ يجب إعادة الاستخراج وتحديث هذا الملف
  و`NOTICE` معاً.

## 8. ما يجب فعله عند إضافة مصدر جديد

1. التحقق من الملكية والترخيص كتابياً.
2. إضافة صف في جدول المصادر هنا وفي `NOTICE`.
3. توثيق الالتزام/البصمة والتاريخ.
4. عدم الدمج قبل مراجعة بشرية معلنة.
5. تحديث «الحدود الصادقة» في `README.md`.

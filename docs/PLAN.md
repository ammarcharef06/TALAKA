# طَلَاقَة | TALAQA — الخطة الرسمية للمشروع

> **الاسم**: طَلَاقَة (Talaqa) — أكاديمية العرب السيادية للغة الإنجليزية
> **English**: TALAQA — The Sovereign English Academy for Arabs
> **المسار البرمجي الداخلي**: AREN (اسم المجلد / الاسم التقني للمشروع)
> **الشعار اللفظي**: «من الصفر إلى C2» / *From Zero to C2*
> **الحالة**: المسار الأكاديمي مكتمل — الإصدار 0.14.0 يشمل البوابة، القبول، تحديد المستوى، البطاقة، الفصل (42 درساً من S0 إلى C2)، ردهة التكرار المتباعد (263 بطاقة)، مقهى طَلَاقَة، امتحانات A1 حتى C2 المعتمدة، السجل الأكاديمي الحيّ، الشهادة الموقعة رقمياً مع صفحة تحقق مستقلة، المكتبة المتدرّجة (14 نصاً أصلياً — نصان لكل مستوى)، والمسار المهني (4 مقابلات بتقييم حتمي + صانع سيرة ذاتية + بطاقات SRS مهنية). **المحتوى التعليمي الأساسي معتمد بشرياً منذ 2026-11-06**، ومحتوى المسار المهني الجديد **آلي الكتابة وينتظر المراجعة البشرية**. المتبقي: طبقات الوكلاء LLM، والوقت السائل، وقرار DID/بلوكتشين.

---

## 1. الرؤية باختصار
توأم رقمي لمؤسسة تعليمية عريقة — أكاديمية إنجليزية كاملة End-to-End للعربي، من الصفر المطلق إلى C2،
بمرونة زمنية مطلقة، تعمل بلا بشر، بلا خادم، بلا تكلفة، وتعيش على جهاز المتعلم.

## 2. القرارات المعتمدة (والأسباب)

### أ) المنصة: تطبيق ويب (PWA)
- يعمل على كل جهاز، يُثبَّت كتطبيق بلا متاجر أو اقتطاع، ويُخدَّم كملفات static.
- يتوافق تماماً مع «اللامركزية المطلقة»: لا خادم يمكن أن يسقط، وأي ميرور أو نسخة محلية تكفي للاستمرار.

### ب) المحرك الذكي: طبقات تصعيدية (لا نموذج واحد يلمّع كل شيء)
| الطبقة | الوصف | متى |
|--------|-------|-----|
| 0 | محرك اختبار تكيفي حتمي (Rule-based) + وكيل «مكتب القبول» سكريبتي | النسخة الأولى — أساس صلب offline، صفر تكلفة |
| 1 | نموذج صغير داخل المتصفح (WebLLM/transformers.js) للحوار الحر — تنزيل اختياري | بعد ثبات النسخة الأولى |
| 2 | ربط Ollama محلياً (`localhost:11434`) للأجهزة القوية | مرحلة المعلم الافتراضي |
| 3 | مفتاح API يملكه المستخدم لتقييم كتابة/محادثة W2+ | مرحلة C1/C2 |

### ج) السيادة / اللامركزية: static + Offline-First معاً
- **لا خادم إطلاقاً**: كل المنطق والمحتوى ملفات static تُرفع على GitHub Pages + Cloudflare Pages + IPFS (CID ثابت)، مع توثيق «كيف تستضيف نسختك» في `DEPLOY.md`.
- **Offline-First**: Service Worker يخزّن كل الأصول؛ البيانات في **IndexedDB** على الجهاز فقط.
- **صفر تحليل، صفر تتبع، صفر حسابات، صفر ملفات تعريف**.
- **تصدير/استيراد «ملف بطاقة الطالب»** إلزامي عند التسجيل (حماية من مسح بيانات المتصفح).
- الشهادات موقَّعة محلياً عبر Web Crypto (ECDSA P-256) — المفتاح الخاص لا يغادر الجهاز ولا يُرفع أبداً؛ التحقق يتم بالمفتاح العام المدمج في ملف الشهادة نفسها، والبصمة SHA-256 مطبوعة للمقارنة اليدوية مع الجهة المصدرة — لا خادم ولا بلوكشين. المطابقة المؤسسية المؤتمتة للبصمة مرحلة لاحقة.

### د) الجمهور واللغة
- الجمهور: **كل العرب**. لغة الشرح: **العربية الفصحى**.
- المحتوى يستهدف **علاج أخطاء العرب الشائعة** كحمض نووي للمنهج (a/an، the، present simple/continuous، الكلمات المشابهة ظاهرياً false friends…).

### هـ) المحتوى: يولّده الذكاء — بضوابط
- بنك الأسئلة وكل محتوى المناهج اللاحق يولد بالذكاء، لكن مع:
  1. **مُتحقق آلي عند البناء** (build-time validator): لا خياران صحيحان، لا إجابة خارج النطاق، لا معرفات مكررة، نوع كل سؤال موسوم.
  2. **تدقيق بشري لعيّنة** من صاحب المشروع قبل أي إطلاق — **تم 2026-11-06**: بنك الأسئلة والدروس ونصوص المكتبة صارت مراجعة بشرياً بالكامل، ولم يعد إطلاقها منتظراً على تدقيق خارجي.
  3. **حزم محتوى مُصدَرة (versioned content packs)** قابلة للتحديث عبر تحديث التطبيق فقط — لا تعديل خادم.

### و) الهوية البصرية: بقوة المشروع
- **الخطوط**: Amiri (عناوين — تُستضاف ذاتياً) + IBM Plex Sans Arabic (متن — ذاتياً). ممنوع CDN الخارجي.
- **اللوحة**: زمردي سيادي `#0E3B2C` • ذهبي مصهور `#C9A227` • عاجيّ ورقّي `#F7F3E9` • حبري `#1A1A18`.
- **الشعار**: ختم دائري جامعي — حرف «ط» مدمج مع منارة/ريشة قلم، وعلى الإطار: «طَلَاقَة • TALAQA • من الصفر إلى C2».
- **شخصية كل شاشة**: وثيقة رسمية (خطوط ذهبية رفيعة، ختم مائي، رقم مرجعي) — «هذه مؤسسة، لا تطبيق».
- **الأرقام والتسميات**: رقم الطالب بصيغة ختم `TALAQA-2026-XXXX-خ`، بطاقات ورسائل رسمية الطابع.

### ز) التقنية: Vite + TypeScript خام — بلا framework وبلا اعتماديات تشغيلية
- كود متين مُتحقَّق منه، يُبنى إلى ملفات static نقية، ديمومة كاملة.
- IndexedDB عبر ملف تغطية صغير مكتوب يدوياً (~40 سطر) بدل مكتبات — اعتمادياتنا حرفياً صفر في الإنتاج.

## 3. نطاق النسخة الأولى (MVP) — «البوابة ومكتب القبول»

**الداخل:**
1. بوابة الأكاديمية (شاشة هبوط بهوية المؤسسة)
2. مكتب القبول: الوكيل «الأستاذ راشد» (سكريبتي) — ترحيب، جمع الاسم/العمر/الهدف/المدة اليومية
3. اختبار تحديد المستوى التكيفي (قواعد + مفردات + فهم مقروء) ~15–20 سؤال بمعايرة S0→C2
4. التسجيل الرسمي: «طلب التحاق» → **رقم طالب** + **بطاقة طالب رقمية** (IndexedDB + تصدير ملف)
5. شاشة النتيجة: المستوى + الثقة + تشخيص أهم نقاط الضعف + التوجيه للمستوى
6. «مبنى الأكاديمية» كاملاً بحالة **يُفتتح قريباً** (فصول/مكتبة/مقهى/امتحانات/Career Hub) — تيلزر صادق للرؤية
7. PWA كاملة: تثبيت، عمل بلا إنترنت، تحديث نسخات

**الخارج (بوعي):** الدروس الفعلية، المعلم الافتراضي LLM، المكتبة، المقهى، SRS، قاعات الامتحان، الشهادات الموقعة، Career Hub، الحسابات السحابية — كلها مراحل لاحقة بنفس المبادئ.

## 4. محرك تحديد المستوى — المواصفة
- **البنية**: بنك أسئلة موسوم `{id, section, cefrGuess, difficulty(0–100), arabicErrorTags[], questionAr, options[], answerIndex, explanationAr}`.
- **الخوارزمية**: افتراض مبدئي B1؛ تحديث تدرجي للاحتمال بعد كل إجابة (تقريب Elo/IRT مبسط)؛ التوقف عند ثقة ≥ 85% أو حد 20 سؤالاً؛ تمرير على الأقسام الثلاثة.
- **الثقة**: عالية / متوسطة / ينبغي إعادة الاختبار.
- **المخرجات**: المستوى + الثقة + تقرير «أخطائك الأقرب للعلاج» (يخرس التسويق ويبني المصداقية).

## 6. المخاطر المعروفة (ومواقفنا منها)
1. **جودة بنك الأسئلة المولّد** → تحقق آلي + تدقيق فاحص (عيّنة ≥ 30 سؤالاً) — **اكتمل**: المراجعة البشرية للمحتوى التعليمي تمت 2026-11-06. محتوى المسار المهني (32 سؤالاً ونماذجه وألفاظه) **لم يُراجَع بشرياً بعد** — يُعلن ذلك في الواجهة والتوثيق، والمراجعة خطوة تالية.
2. **تقييم المقابلة الحتمي** → يقيس رصد الكلمات المفتاحية فقط، لا النبرة ولا الطلاقة ولا صحة المضمون؛ يُعرض كنصيحة تدريبية صريحة، ولا يُقدَّم كبديل عن محاور بشري أو كحكم توظيف.
3. **مسح بيانات المتصفح** → تصدير البطاقة إلزامي؛ التنبيه واضح في شاشة التسجيل.
4. **ضجيج تحديد المستوى** → عرض «ثقة» وحق الإعادة؛ لا كَذب أكاديمي إطلاقاً.
5. **اسم «Talaqa» قد يكون مسجلاً كعلامة** → فحص سريع قبل أي إطلاق عام.
6. **الذاكرة على الأجهزة الضعيفة** → لا تحميل نماذج افتراضياً؛ كل شيء static خفيف.

## 7. ما بعد MVP (خارطة الطريق باختصار)
المسار الأكاديمي والمهني S0→C2 مكتمل: فصول + مكتبة متدرجة + مقهى محادثات + تكرار متباعد + قاعات امتحانات مشددة + السجل الأكاديمي + الشهادة الموقعة رقمياً + المسار المهني (مقابلات وسيرة). **التالي:** مراجعة بشرية لمحتوى المسار المهني، ثم طبقات الوكلاء LLM (WebLLM/Ollama/مفتاح المستخدم)، والوقت السائل، وقرار DID/بلوكتشين، وتوزيع IPFS الكامل + وثائق السيادة.
